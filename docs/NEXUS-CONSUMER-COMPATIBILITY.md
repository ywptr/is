## Collision and mapping rules

1. Create a read-only inventory of each consumer's legacy tenant/user IDs, verified identity links and local role semantics under separate authorization. Verify business ownership independently; matching names, UUID strings, domains or emails do not prove sameness. Record the manifest owner/reviewer, source environment and evidence references without copying sensitive user data into Git.
2. A valid IG UUID not present in Nexus may be imported **with that exact UUID** through a reviewed, explicit import mechanism; the current tenant-creation API generates UUIDs and must not be used to silently renumber legacy tenants. Do not introduce that import API as part of the consumer API.
3. An IG UUID already representing the verified same business tenant is reused. Reconcile keys, lifecycle, memberships and domains explicitly; never overwrite a conflicting tenant key or increase privilege automatically.
4. If the same UUID represents a different business tenant, quarantine both mappings from consumer access. Choose an explicitly reviewed canonical destination and a durable source-qualified map `(source_application, source_environment, legacy_tenant_id) → canonical_nexus_tenant_id`. Only genuinely conflicting/invalid IDs require a new canonical UUID. Never rewrite existing consumer PKs/foreign keys merely to align Nexus; map at the boundary until a separately authorized consumer migration.
5. Invalid/non-UUID legacy IDs require an explicit map with uniqueness/collision checks, not hashing/truncation or random per-request UUIDs. Local→canonical mapping is environment-qualified and immutable once approved, with audited supersession rather than silent edits. Within a workflow, downstream calls always carry the canonical UUID, never another application's legacy ID.
6. Identity links require proof and must preserve historical local users; apply one-to-one constraints to the appropriate issuer namespace. Suspicious many-to-one links, duplicate Google subjects or missing provenance block the affected records. Password-only and ambiguous cases never auto-enroll.
7. Role reconciliation records the local role and intended central role separately. A local workspace/project admin is not automatically a Nexus tenant owner/admin. A verified active central member may still lack every local resource permission. Preserve original local role records for rollback and support review of grant differences.

## Safe sequencing and cutover

- Verify deployed Stage 1 code/flag, target schema, tenant governance and last-admin invariant first. User-reported 0007 application is not consumer readiness.
- Review manifests, collisions, identity-link proof, domain approvals and service/operation grants in an isolated environment. Import only after separate migration authorization; never use sign-in or domain resolution as an import trigger.
- Ship Nexus v1 dark, with no consumer behavior change. Obtain independent IG/Sandcastle/Axtor change authorization and implement shadow reads/decisions that cannot grant or mutate resources. Compare against current local enforcement; disagreement denies/blocks cutover, never takes the more permissive union.
- Enable per-app/per-tenant cohorts only after end-to-end actor/audience/proof, matching canonical UUID, negative tests and stale-access deadlines pass. Keep original sessions and local resource checks. Once central authorization is enforced, Nexus unavailability must deny; rollback must not silently fall back to a legacy policy that ignores a recorded central revocation.
- For a security-affecting rollback, freeze protected operations for affected cohorts, restore compatible application code/config and review local/central policy differences before re-enabling. Preserve mapping/identity-link manifests, grants, audit and original data; reconcile queued work and existing consumer sessions. A rollback flag is not permission to reinstate revoked access.

All consumer schema/code/migration changes described here are future handoffs; none is authorized or performed in this IS contract-only task.
